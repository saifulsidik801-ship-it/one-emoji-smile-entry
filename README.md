One emoji, and nothing else — the one most likely to make a stranger smile.

Entry for [One Emoji, One Smile](https://make.fun/bounty/u-0xkianno-one-emoji-one-smile-5470751f) on make.fun. The program writes a single emoji to `/output/entry.txt`: 🫠 Melting Face — a smiling face melting with warmth. Warm and friendly at first glance, gently funny, understood by any stranger of any age or background, plainly chosen rather than the first default smiley, and right coming from someone unknown.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

## Output

`/output/entry.txt` contains exactly one emoji (4 bytes, UTF-8, no trailing newline):

```
🫠
```
